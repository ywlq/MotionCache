# Using MAGI-1 in ComfyUI

## Installation

1. [Download ComfyUI and install](https://github.com/comfyanonymous/ComfyUI?tab=readme-ov-file#manual-install-windows-linux) using manual installation

2. Install MAGI-1 nodes

    Method 1: Install using comfy-cli (recommended)

    After installing [comfy-cli](https://github.com/Comfy-Org/comfy-cli?tab=readme-ov-file#installation), run the following command in the terminal:
    ```shell
    cd ComfyUI

    comfy node registry-install MAGI-1
    ```

    Method 2: Install from source

    Download this repository to *ComfyUI/custom_nodes/MAGI-1* path and [install the corresponding dependencies](https://github.com/SandAI-org/MAGI-1?tab=readme-ov-file#environment-preparation).

    > ⚠️ To enable ComfyUI to recognize custom nodes, both methods require moving `comfyui/__init__.py` to the root directory of the MAGI-1 project.

3. Download MAGI-1 model files locally. In MAGI-1's configuration file, for example in `example/4.5B/4.5B_base_config.json` (if using the 4.5B base model), modify the model weight paths to local absolute paths. The following three file paths need to be modified:
    * **load**: Absolute path to DiT model weights
    * **t5_pretrained**: Absolute path to T5 model weights
    * **vae_pretrained**: Absolute path to VAE model weights

## Node Features

After installation, start ComfyUI in the ComfyUI directory

```shell
cd ComfyUI
# If comfy-cli is installed
comfy launch
# Otherwise
python main.py
```
You can find the nodes provided by this repository in ComfyUI's *Add Node - Magi* menu. In newer ComfyUI versions, nodes can also be found in the NODE LIBRARY on the left side of the interface.

### Load Prompt

Used to load a prompt text from input for subsequent text encoding processing.

* **prompt**: The text content entered by the user, supports multi-line input.

### T5 Text Encoder

Used to encode prompt text into text features (Conditioning Embedding) for video generation.

* **prompt**: The input description text.
* **t5\_pretrained\_path**: Absolute path to T5 model weights, pointing to the pretrained model in the `ckpt/t5` directory.
* **t5\_device**: Specify which device to load and run the T5 model on, options are `"cpu"` or `"cuda:x"` (e.g., `"cuda:0"`).

### Load Image

Used to load image files from the input directory. Supports uploading images through the file selector.

* **image\_path**: Select image files from ComfyUI's input folder. The system automatically filters non-image file types and only displays supported image formats.


### Process with MAGI

Core node for text-to-video, image-to-video, and video continuation tasks, generating corresponding video sequences and passing the frame rate to the subsequent video save node.

* **task\_mode**: Specify which task to execute among *text-to-video, image-to-video, video continuation*.
* **config\_path**: Absolute path to the JSON configuration file required for model running.
    > ⚠️ All paths appearing in the configuration file also need to be absolute paths.
* **image\_path**: Absolute path to the image/video to be converted to video.
* **text\_embeddings**: Embedding features and mask generated by the text encoder, serving as semantic guidance for video generation.
* **magi\_seed**: Seed for generating random numbers, used to control the reproducibility of model generation. The same seed will produce the same video output. Default value is 1234, range is 0~100000.
* **video\_size\_h**: Height of the generated video (pixels). Default value is 720. Setting too high will cause slow running speed and memory overflow issues, please set carefully.
* **video\_size\_w**: Width of the generated video (pixels). Default value is 720. Setting too high will cause slow running speed and memory overflow issues, please set carefully.
* **num\_frames**: Total number of video frames, controlling the duration of the generated video. Default value is 96, range is 24~24000.
* **num\_steps**: Number of diffusion sampling steps. More steps result in higher image quality but longer inference time. Default value is 64, range is 4~240.
* **fps**: Frame rate of the generated video (frames per second), affecting the playback speed and smoothness of the video. Default value is 24, supported range is 1~60.

> ⚠️ This node sets a series of distributed and memory-related environment variables before running.


### Save Video

Save the generated video sequence as a local file.

* **video**: The video tensor to be saved, essentially a torch.Tensor.
* **output\_path**: Absolute path to save the video (only `.mp4` suffix is allowed).
* **fps**: Video frame rate, default is 24, supports integer settings from 1 to 60.

The video will be encoded with the specified frame rate and written to `output_path`.


## Workflow Examples

This section shows image-to-video workflow examples. You can import workflows through the *Load* button in the menu. In newer ComfyUI versions, you can load workflows through *Workflow - Open* in the upper left menu, or copy the workflow file to ComfyUI's `user/default/workflows` directory, then refresh in the left *Workflow* panel to find it.

The workflows are located in the `comfyui/workflow/` directory, and the assets are located in the `example/assets/` directory.

After importing the workflow, **you need to manually re-specify the corresponding file paths**.

### Text to Video

The workflow corresponds to the `workflow/magi_text_to_video_example.json` file.

### Image to Video

The workflow corresponds to the `workflow/magi_image_to_video_example.json` file.

### Video Continuation

The workflow corresponds to the `workflow/magi_video_continuation_example.json` file.
