# MOTION CACHING FOR AUTOREGRESSIVE VIDEO GENERATION

This repository is the official implementation of the paper **"Motion Caching for Efficient Autoregressive Video Generation."** We implement MotionCache on two representative autoregressive video generation models: **[MAGI-1](MotionCache4MAGI-1/)** and **[SkyReels-V2](MotionCache4SkyReels-V2/)**. For model-specific implementation details of MotionCache, please refer to the corresponding folders.
